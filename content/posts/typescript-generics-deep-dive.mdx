## 为什么需要泛型？

没有泛型的 TypeScript 就像只会喊"这是个东西"的描述符——准确但毫无用处。

```typescript
// ❌ 糟糕：失去类型信息
function identity(arg: any): any {
  return arg
}

// ✅ 优雅：保留并传递类型信息
function identity<T>(arg: T): T {
  return arg
}

const result = identity("你好") // result 类型为 string，而非 any
```

## 泛型约束

使用 `extends` 关键字限制泛型的范围：

```typescript
// 约束 T 必须有 length 属性
function logLength<T extends { length: number }>(arg: T): T {
  console.log(`长度为：${arg.length}`)
  return arg
}

logLength("字符串")      // ✅ string 有 length
logLength([1, 2, 3])     // ✅ array 有 length
logLength(42)            // ❌ number 没有 length，编译报错
```

## 条件类型与 infer

`infer` 是泛型体系中最神奇的关键字，用于在条件类型中**推断并捕获**类型：

```typescript
// 提取函数返回类型（标准库 ReturnType 的实现原理）
type MyReturnType<T extends (...args: any) => any> =
  T extends (...args: any) => infer R ? R : never

type Result = MyReturnType<() => string> // string

// 提取 Promise 内部类型
type Awaited<T> = T extends Promise<infer U> ? Awaited<U> : T

type Resolved = Awaited<Promise<Promise<number>>> // number
```

## 内置工具类型实现

理解原理，才能用好工具：

```typescript
// Partial<T>：所有属性变可选
type MyPartial<T> = {
  [K in keyof T]?: T[K]
}

// Required<T>：所有属性变必选
type MyRequired<T> = {
  [K in keyof T]-?: T[K]  // -? 移除可选修饰符
}

// Pick<T, K>：选取部分属性
type MyPick<T, K extends keyof T> = {
  [P in K]: T[P]
}

// Exclude<T, U>：从联合类型中排除
type MyExclude<T, U> = T extends U ? never : T
type Result = MyExclude<"a" | "b" | "c", "a"> // "b" | "c"
```

## 实战：类型安全的 API 客户端

```typescript
interface Endpoints {
  '/users': { response: User[] }
  '/posts': { response: Post[] }
  '/user/:id': { params: { id: string }; response: User }
}

async function request<Path extends keyof Endpoints>(
  path: Path,
  options?: { params?: Endpoints[Path] extends { params: infer P } ? P : never }
): Promise<Endpoints[Path]['response']> {
  // 实现略
  const res = await fetch(buildUrl(path, options?.params))
  return res.json()
}

// 全程类型安全，包括返回值
const users = await request('/users')  // User[]
const user = await request('/user/:id', { params: { id: '123' } }) // User
```
